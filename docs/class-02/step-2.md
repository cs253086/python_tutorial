# ⭐ Step 2 — A box for your name

Variables can hold **words** too, not just numbers. A word in Python
is called a **string** — because it's like a string of letters.

Add this **above** your score line:

```python
name = "Leo"
```

(Use your own name! Keep the quotes.)

Your code should now start like this:

```python
print("🐍 Welcome to Snake!")
print("Eat the apples. Don't bite yourself!")
print("Press an arrow key to start.")
print("Good luck, Leo!")

name = "Leo"
score = 0
print(name)
print(score)
```

Tap **▶ Run**. You should see your name and `0` at the end.

## 🎉 Two variables, two boxes!

`name` holds the word `"Leo"`. `score` holds the number `0`.
