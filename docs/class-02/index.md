# Class 2 — Remember things! 🧠

Today you'll teach the computer to **remember** stuff — like your
name and how many apples you've eaten.

---

## 📦 What's a variable?

Imagine a **box with a label** on it. You write the label on the
box, put something inside, and later you can say the label and
Python tells you what's inside.

That's a **variable** in Python.

- The **label** is the name (like `score`)
- What's **inside** is the value (like `0`)
- You put something inside with `=` (like `score = 0`)

It's like saying:

> "Computer, I'm calling this box `score`, and I'm putting the
> number `0` inside."

## 🤔 Why bother?

Because now you can use that name **anywhere** and Python will
look inside the box for you.

When the player eats an apple later, you'll write:

```
score = score + 1
```

Which means: "Look inside the `score` box, add 1, and put the new
number back." Your game can count!

## 🎁 One more thing: f-strings

At the end of the class you'll also meet **f-strings** — a way to
put a variable **inside** a sentence. It looks like this:

```
print(f"Hi, {name}!")
```

The `f` in front and the `{curly braces}` tell Python:
*"slide whatever's in the `name` box into this spot."*
