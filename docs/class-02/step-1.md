# ⭐ Step 1 — Give a name to a number

Open your `snake` trinket.

Below your welcome lines, add these **two lines**:

```python
score = 0
print(score)
```

Your code should look like this:

```python
print("🐍 Welcome to Snake!")
print("Eat the apples. Don't bite yourself!")
print("Press an arrow key to start.")
print("Good luck, Leo!")

score = 0
print(score)
```

Tap **▶ Run**.

You should see `0` at the end of the output.

## 🎉 You made a variable!

`score` is a **box** you made called `score`, with the number `0`
inside. When you `print(score)`, Python prints what's in the box.

> 💡 **Try it**: change `score = 0` to `score = 100`, tap Run, and
> watch the number change.
