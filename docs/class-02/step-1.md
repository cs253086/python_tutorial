# ⭐ Step 1 — Make your first variable

Let's put a **score** in a box called `score`, starting at `0`.

Below your welcome lines, add these **two lines**:

```python
score = 0
print(score)
```

Tap **▶ Run**. You should see `0` at the end of the output.

## 🔍 Notice

- **`score`** is the name of the box you made up. You can pick any
  name (as long as it doesn't have spaces).
- **`=`** means *"put this value into the box."* It's **not**
  "is equal to" — that's `==` (two equals) which you'll meet next
  class.
- **`print(score)`** asks Python: *"what's in the `score` box?"*
  and prints it.

## 🧪 Try changing it

Change `score = 0` to `score = 100` and tap Run. The number
changes! That's because Python prints whatever is currently in the
box.
