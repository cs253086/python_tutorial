# 🏆 You did it!

You finished **Project 2 — Target Practice!** 🎯

## What you built

- A bullseye target drawn with three concentric `turtle` circles
- Random arrows landing somewhere on (or near) the target
- A score from 0 to 10, picked by Python based on how close to
  the centre the arrow landed

## 🧠 What you learned

- **`turtle.circle`** and **`begin_fill` / `end_fill`** — drawing
  filled circles
- **`pen.dot(N)`** — drawing a quick dot
- **`math.sqrt`** and the `**` power sign — measuring distance
- **`if` / `elif` / `else`** — picking between options
