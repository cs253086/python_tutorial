## What we changed

- **Adapted the inline editor** — the original uses Trinket; this
  derivative uses an in-browser Skulpt-based editor.
- **Adapted graphics library where relevant** — the original uses
  the `p5` library for projects 2–6; this derivative uses Python's
  built-in `turtle` library to fit our editor.
- **Adjusted wording** for accessibility to younger English
  speakers (9-year-olds).
- **Restructured the page layout** to match this site's existing
  conventions (per-step pages, runnable editors, solution toggle).
