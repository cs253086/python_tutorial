# 🏆 You did it!

You finished **Project 1 — Hello World!** 🎉

## What you built

A fun interactive Python program with:

- A welcome message and the world emoji
- A big multiplication (`111,111,111 × 111,111,111`)
- The current date and time
- A custom dice the player picks the sides for
- One 🔥 emoji for every point on the roll

## 🧠 What you learned

- **`print()`** — show words on the screen
- **Variables** — boxes that hold things
- **f-strings** — sentences with variables inside
- **Math operators** (`+`, `-`, `*`, `/`, `**`)
- **`import`** and modules — bringing in extra tools (`datetime`, `random`)
- **Functions** with `def` — naming a chunk of code
- **`randint`** — picking a random number
- **`input()`** — getting an answer from the player
- **`int()`** — changing text to a number (type casting)
- **String multiplication** (`emoji * number`)

That's a LOT! 🔥
