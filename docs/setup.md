# How the tutorial works 🛠️

**There's nothing to install.** Python runs **right in the page**
— every code box has a **▶ Run** button next to it.

Tap Run on a box → see the output → change the code → tap Run
again. That's the whole loop.

## What you need

- An iPad (or any computer) with a browser.
- A **keyboard** helps — Python needs lots of symbols like `"` and
  `(`.

## First time only

The first time you tap ▶ Run on any page, Python takes a few
seconds to load (it has to download once). After that it's
instant. Your browser remembers it.

## If you get stuck

- Red error message? That's **Python** telling you what's off. Read
  it slowly — usually it says the line number and what it expected.
- Output looks wrong? Use the **↺ Reset** button next to Run to put
  the original example back, then try again.
- Page frozen? Refresh it. Your edits are saved automatically.

## iPad tips

- Python needs **straight quotes** `"..."`. If the iPad turns them
  curly, retype them.
- **Long-press** a key to get extras like `:`, `[`, `(`.
- Add the site to your **Home Screen**: Safari share →
  *Add to Home Screen*. Then tap the 🐍 icon to jump straight to
  the tutorial.
