# Class 47 — Which way? 🧭

Last class your snake got a **clock**. But the clock doesn't know
which way the snake should go. Today you'll give the snake a
**`direction`** — a single box that holds "UP", "DOWN", "LEFT",
or "RIGHT".

## 🎯 Today you'll
- Meet `direction` — a variable that holds one of four words
- **Read** the direction from inside `tick()` every frame
- Print which way the snake is heading, 5 times per second

- 🧩 **2 steps**
- ⏱️ About 10 minutes
- 🐍 **By the end:** the program prints `going RIGHT` every tick.
  (The snake STILL doesn't move — we use direction to do the math
  in Class 48.)
