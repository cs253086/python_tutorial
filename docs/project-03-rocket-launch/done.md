# 🏆 You did it!

You finished **Project 3 — Rocket Launch!** 🚀

## What you built

- A starry night sky drawn with 30 random stars
- A silver rocket that flies upward across 50 frames
- An orange smoke trail behind the rocket

## 🧠 What you learned

- **`for` loop** with `range(N)` — do something N times
- Loop variables (`i`, `step`) — a counter that changes each turn
- Updating a variable inside a loop (`rocket_y = rocket_y + 8`)
  to animate things
- Drawing dots with `pen.dot(N)`
