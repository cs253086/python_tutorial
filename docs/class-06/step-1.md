# ⭐ Step 1 — Start fresh

Open your `snake` trinket.

**Select all your code and delete it.** 😱

(Don't worry — you don't need it anymore! You've learned everything
it had to teach you. Now we build the real game.)

Your code box should be empty.

At the top, type this **one line**:

```python
import turtle
```

Tap **▶ Run**.

Nothing should happen visibly — no output, no errors. That's fine!
It means Python loaded the **turtle** tool, ready to use.

## 🎉 You imported a tool!

`import` tells Python: *"Hey, bring in that tool for me."*
`turtle` is the tool for drawing.
