# 🏆 You drew the snake!

You finished Class 8. Here's what you learned:

- **Lists** `[a, b, c]` — hold a bunch of things.
- **Tuples** `(x, y)` — a pair of numbers, good for spots on
  screen.
- **`for part in list:`** — do something for each item in a list.
