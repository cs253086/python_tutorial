# ⭐ Step 2 — Make the snake

A snake is a line of **squares**. Each square is at a **spot** —
two numbers: an `x` and a `y`. Two numbers grouped together is
called a **tuple**: `(x, y)`.

So the whole snake is a list of tuples. Like this:

```python
snake = [(-40, 0), (-20, 0), (0, 0)]
```

That's 3 body parts in a row, with the **head at the end**.

In your snake trinket, add this line **after** the checkerboard
loop (before `screen.mainloop()`):

```python
snake = [(-40, 0), (-20, 0), (0, 0)]
```
