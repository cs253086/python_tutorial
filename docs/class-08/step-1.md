# ⭐ Step 1 — Meet lists

A **list** is a bunch of things in square brackets `[ ]`, with
commas between them.

Try this in a fresh area:

```python
fruits = ["apple", "banana", "cherry"]
print(fruits)
print(fruits[0])
print(fruits[2])
```

Tap **▶ Run**.

You should see:

```
['apple', 'banana', 'cherry']
apple
cherry
```

## 🎉 Lists hold multiple things!

`fruits[0]` gets the **first** thing in the list. Python starts
counting at **0**, remember?

- `fruits[0]` → `"apple"`
- `fruits[1]` → `"banana"`
- `fruits[2]` → `"cherry"`
