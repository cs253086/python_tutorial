# ⭐ Step 1 — Random numbers

Python has a tool called **random** — perfect for surprises like
where an apple shows up.

Try this in a fresh area:

```python
import random

print(random.randint(1, 6))
print(random.randint(1, 6))
print(random.randint(1, 6))
```

Tap **▶ Run**.

You should see **3 random numbers** between 1 and 6 — like rolling
dice!

Run it again — different numbers. 🎲

## 🎉 You rolled dice with code!

`random.randint(1, 6)` picks a random number between 1 and 6,
including both ends.
