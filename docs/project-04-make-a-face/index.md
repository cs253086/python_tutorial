# Project 4 — Make a Face 😃

Design and draw your own face (or a monster, or an alien) using
shapes you already know how to draw.

This is your **first Design project** — the steps show you how
to make a sample face, then you make your own.

## 🎯 What you'll build

A face on screen made of circles, rectangles, and triangles —
whatever you can imagine.

## 🧩 Python you'll meet

No brand-new Python ideas! You'll use what you learned in
Projects 1–3:

- `turtle` shape drawing (`pen.circle`, `pen.dot`, `begin_fill` /
  `forward` / `left`)
- Functions to make a shape recipe you can reuse
- `for` loops (if you want lots of the same shape)

- 🧩 **5 steps**
- ⏱️ About 30 minutes
- 🎨 Type: **Design** (less following, more creating!)
