# 🏆 Class 11 done!

Real game with a real ending. 💀🔄

## What you learned
- A boolean **`running`** flag to gate the whole tick
- A `show_game_over()` banner with the final score
- A `reset_game()` function that puts every value back to start
- An **R** key to launch a fresh round

You now have a **complete, playable Rally-X**: drive, collect,
dodge, smoke, score, lose, restart. 🎮
