# Class 11 — Game over 💀

A game without an end isn't really a game. Today you'll add a
proper **GAME OVER** banner when fuel runs out or lives reach 0,
plus a **press `R` to restart** flow.

## 🎯 Today you'll
- Add a `running` flag to `state`
- Show a big **GAME OVER** screen when it flips off
- Press **R** to reset and start over

- 🧩 **2 steps**
- ⏱️ About 20 minutes
