# Class 4 — Build the maze 🧱

Today you'll lay down the **maze** — a list of cyan wall blocks
that the cars will drive around.

## 🎯 Today you'll
- Store wall positions in a **list of tuples**
- Write a function that draws every wall in one loop
- See your Rally-X go from "cars in empty space" to "cars in a
  real maze"

- 🧩 **2 steps**
- ⏱️ About 15 minutes
