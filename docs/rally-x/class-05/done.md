# 🏆 Class 5 done!

Your car drives! 🎮

## What you learned
- Methods that **change** `self`'s data (`update`, not just `draw`)
- The **game-loop pattern**: tick → update → draw → schedule next
- Wiring arrow keys with `screen.listen()` + `screen.onkey(...)`

## What to expect
- The red car keeps moving in the last direction you pressed
- It can drive **through** walls — Class 6 will fix that
- Enemies still stand still — Class 8 will make them chase
