# 🏆 Class 2 done!

You wrote your first class. ✅

## What you learned
- **`class`** — Python's cookie cutter
- **`__init__(self, ...)`** — the setup recipe that runs when you
  make a new instance
- **`self`** — *"this particular cookie"* — how each instance
  knows about itself
- **Methods** — functions inside a class, like `draw(self)`

## What your file does now
- Opens the Rally-X window
- Defines a reusable `Car` class
- Creates one player car and draws it
