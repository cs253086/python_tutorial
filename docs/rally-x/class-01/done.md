## Next class → 🏗️ The `class` keyword

Right now your car is just a square. Real Brawl-Stars-style
games have **many** cars (you, chasers, maybe more). We don't
want to copy-paste the same code for every car — that's where
**classes** come in.

A `class` is like a **cookie cutter**: you write it once, then
stamp out as many cookies (cars) as you want, each with its own
position and color.

In Class 2 you'll meet `class Car:` for the first time.
