# Class 10 — Smoke screen 💨

The classic Rally-X weapon: tap **Space** and you drop a cloud
of smoke behind you. **Chasers freeze** for a few ticks.

## 🎯 Today you'll
- Add a `smoke` count + a `smoke_timer` to your `state` dict
- Tap Space to deploy smoke (uses one charge)
- Pause every enemy until the timer runs out

- 🧩 **2 steps**
- ⏱️ About 20 minutes
