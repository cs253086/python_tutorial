# 🏆🎊 YOU BUILT SNAKE! 🐍

You did it. From nothing — just a blinking cursor — you built a
whole working game.

## Everything you learned

- **Class 1** — `print` and quotes
- **Class 2** — variables
- **Class 3** — `input` (asking questions)
- **Class 4** — `if` / `else` (making choices)
- **Class 5** — `while` loops (doing it again)
- **Class 6** — `turtle` — opening a window
- **Class 7** — `for` loops — drawing a grid
- **Class 8** — lists and tuples — the snake's body
- **Class 9** — key events — arrow steering
- **Class 10** — functions and parameters — tidy code
- **Class 11** — `random` — the apple
- **Class 12** — collisions and game over

That's **twelve big Python ideas**, and a working Snake game in
your hands. **Show your parents. Show your friends.** You wrote
every single line.

## What now?

- **Make it yours.** Change the snake color. Speed it up by lowering
  the `150` in `ontimer`. Make the board bigger.
- **Add high scores.** Save the best score to a file between games.
- **Add sound.** Play a *crunch* when the snake eats an apple.
- **Invent a new game.** You've got all the Python you need. Pong?
  Tetris? Something nobody has ever built?
