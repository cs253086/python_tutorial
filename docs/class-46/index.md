# Class 46 — Make it tick ⏰

So far when you draw the snake it just **sits there**. Today
you'll meet **`ontimer`** — Python's way of saying *"run this
function in N milliseconds."* That's the **clock** behind every
video game.

## 🎯 Today you'll
- Meet `screen.ontimer(function, milliseconds)`
- See the trick: a function that schedules **itself** → a loop
- Make your Snake board redraw on a **tick** every 200 ms

- 🧩 **2 steps**
- ⏱️ About 10 minutes
- 🐍 **By the end:** the screen tick-tick-ticks. (The snake still
  doesn't move — we add direction in Class 47.)
