# 🏆 You did it!

You finished Class 46. Here's what you learned:

- **`screen.ontimer(function, ms)`** — schedule a function to run
  later.
- **The clever trick**: a function that schedules itself = a
  forever-loop. The **game loop**.
- **`screen.mainloop()`** keeps the program alive so the timer
  can actually fire.

Your Snake game now has a **clock**. The board redraws 5 times a
second — even though nothing visible has changed yet. The stage
is set. ⏰
