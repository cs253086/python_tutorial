# Flappy Bird — Class 2 — The Bird blueprint 🏗️

So far the bird is a plain circle. Today you'll meet **classes** —
the Python tool for "make a blueprint of a thing, then stamp out
as many of those things as you want, each with its own data."

You'll write `class Bird` with an `__init__(self, x, y)` setup
method and a `draw(self)` method that draws a real bird with
a body, an eye, and a beak.

## 🎯 Today you'll
- Meet `class`, `__init__`, and `self` for the first time
- Give the bird **its own pen** (`self.pen`) inside the class
- Write a `draw()` method that draws body + eye + beak

- 🧩 **2 steps**
- ⏱️ About 15 minutes
- 🆕 New Python: `class`, `__init__(self, …)`, `self.x = x`
