# Flappy Bird — Class 7 — Many pipes 🎲

One pipe forever isn't a game. Today you'll **spawn pipe after
pipe**, each at a random gap height, and clean up the ones that
have scrolled off the left edge.

You'll meet two important Python ideas:

1. A **list of objects** — `pipes = [Pipe(220, 0)]` — and
   iterating over it with a `for` loop
2. The **`random`** module — `random.randint(-100, 100)` to pick
   a random gap height

## 🎯 Today you'll
- Replace the single `pipe` with a list `pipes`
- Use `import random` to pick a random gap each time
- Add a spawn timer that adds a new pipe every ~60 frames
- Remove pipes that have scrolled off the left edge

- 🧩 **2 steps**
- ⏱️ About 15 minutes
- 🆕 New Python: lists that hold things made from a class +
  `random.randint`
