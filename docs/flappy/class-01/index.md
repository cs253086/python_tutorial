# Flappy Bird — Class 1 — Open the sky! 🐤

Welcome to **Flappy Bird**! Over the next 12 classes you'll build the
classic tap-to-flap arcade game: a yellow bird, green pipes, gravity,
score, and game over.

Class 1 is a warm-up — you'll set up the **sky-blue game window**
that the bird and pipes will live in. No new Python yet — this
re-uses turtle from Beginner Snake.

## 🎯 Today you'll
- Open a 400×600 turtle window titled **Flappy Bird**
- Set the sky-blue background
- Stamp the yellow bird in the middle so we know it works

- 🧩 **2 steps**
- ⏱️ About 10 minutes
- 🆕 Fresh file — leave snake.py alone, this is a brand-new game!
