# 🐤 Flappy Bird — Intermediate Python

Twelve classes. You'll build the famous tap-to-flap arcade hit from
scratch — a yellow bird, green pipes, gravity, score, game over,
and a best-score tracker.

Along the way you'll learn the **intermediate** Python you couldn't
fit in the beginner Snake tutorial: classes, methods, multiple
instances, lists of objects, collisions, game state, and
dictionaries.
