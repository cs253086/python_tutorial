# Flappy Bird — Class 9 — Don't crash! 💥

Right now the bird flies through pipes like a ghost. Time to
add **collisions** — touch a pipe and it's GAME OVER.

You'll write a small function that checks whether the bird's
box overlaps the pipe's box. It's just a few `if` statements
on `x` and `y`.

## 🎯 Today you'll
- Write `collides(bird, pipe)` returning `True` if they overlap
- In `tick()`, end the game if the bird hits any pipe
- Also end if the bird flies above the ceiling or below the floor

- 🧩 **2 steps**
- ⏱️ About 15 minutes
- 🆕 New Python: bounding-box collision check, early `return`
