# Flappy Bird — Class 12 — Polish! 🌥️

The game **works** — it's a real, playable Flappy Bird. This is
the polish class: little touches that make it feel finished.

You'll add three things:

1. **Clouds** floating in the sky (static white circles)
2. A **sandy ground** at the bottom
3. A **wing** on the bird that flashes brighter when flapping

No new game mechanics — just visual joy.

## 🎯 Today you'll
- Make a `cloud_pen` and stamp three static clouds
- Make a `ground_pen` and draw the sandy floor once
- Add a wing to `Bird.draw` that changes color based on `vy`

- 🧩 **2 steps**
- ⏱️ About 15 minutes
- 🆕 New Python: nothing brand new — you're the boss now
