# Flappy Bird — Class 5 — The first pipe 🟩

A bird flapping in empty sky isn't much of a game. Today you'll
draw the iconic **green pipes** — a top one hanging from the
ceiling and a bottom one rising from the floor, with a gap to
fly through.

Same `begin_fill` / `forward` / `left` rectangle recipe you used
for the bird's body, but **bigger** and **two of them**.

## 🎯 Today you'll
- Make a separate turtle pen for pipes
- Write `draw_pipe(x, gap_y)` — a function that stamps a top
  pipe and a bottom pipe with a gap of 140 pixels in between
- Call it once to put a pipe in front of the bird

- 🧩 **2 steps**
- ⏱️ About 15 minutes
- 🆕 New Python: drawing parameterized rectangles, separate pens
