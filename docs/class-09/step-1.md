# ⭐ Step 1 — Make your own command

Python has lots of commands like `print` and `input`. You can
**make your own** too, with `def`.

Try this in a fresh area:

```python
def say_hi():
    print("Hi there!")

say_hi()
say_hi()
say_hi()
```

Tap **▶ Run**.

You should see `Hi there!` **three times**.

## 🎉 You made your own command!

`def say_hi():` means *"I'm making a new command called say_hi."*
Then you **call** it with `say_hi()`.
