# ⭐ Step 1 — Meet `for`

A **`for` loop** does something **once for each number** you give it.

Try it in the code box below and try this:

```python
for i in range(5):
    print(i)
```

Tap **▶ Run**.

You should see:

```
0
1
2
3
4
```

## 🎉 You made Python count!

Python started `i` at `0`, printed it, bumped to `1`, printed…
all the way up to `4` (which is `5 - 1`).

> 💡 `range(5)` gives you **5 numbers**: 0, 1, 2, 3, 4. Python
> likes to start counting at **0**!

Try `range(3)`, `range(10)`, `range(1, 6)` (starts at 1, stops
before 6 → gives `1, 2, 3, 4, 5`).
