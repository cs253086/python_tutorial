# Class 1 — Make the computer talk! 🐍

Today you'll write your very first line of Python and make the
computer **say something out loud**.

---

## 🗣️ What's `print`?

Imagine the computer as someone reading a book. The `print`
command hands it a card and says: *"read this card."*

```
print("Hello!")
```

- The **card** is whatever is inside the `(...)`
- The **quotes** `"..."` wrap the exact words
- When Python sees this, it reads `Hello!` in the output

Every time you want the computer to say anything, `print` is how.

## 🔒 Why do we need quotes?

Without quotes, Python thinks you're naming something:

```
print(Hello)   ← Python: "what's Hello? I don't know any Hello."
print("Hello") ← Python: "oh, just say the word Hello. Got it."
```

Quotes tell Python *"these are exact words, not a name."*

## 💬 One more thing: comments

Sometimes you want to leave yourself a note that Python **ignores**.
That's a **comment**. It starts with `#`:

```
# This line is for me. Python won't read it.
print("But this line gets printed.")
```
