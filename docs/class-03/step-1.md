# ⭐ Step 1 — Meet `input`

`input` is a command that **asks the player a question** and waits
for them to type an answer.

At the top of the code below, add this test line:

```python
answer = input("What's your favorite color? ")
print(answer)
```

Tap **▶ Run**.

The output area will wait for you to type. Type a color (like
`blue`), then press **Enter**.

The color you typed should appear right after.

## 🎉 You asked the player a question!

> 💡 The word in the box (`answer`) can be anything you want. It's
> just the name of the box that holds what the player typed.
