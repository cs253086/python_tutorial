# ⭐ Step 3 — Try it!

Tap **▶ Run**.

The game will say `What's your name?` and wait for you.

Type your name and press **Enter**.

You should see:

```
🐍 Welcome, <your name>!
Your score is 0.
```

Now try it again with a **friend's name** or a **silly name** like
`PizzaLord`. See how the game greets them!

Tap **Save** 💾.
