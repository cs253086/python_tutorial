# ⭐ Step 2 — Make it a real countdown

Let's turn your test loop into a **Snake countdown** —
`3… 2… 1… GO!` right before the game starts.

Change the test lines to this:

```python
countdown = 3
while countdown > 0:
    print(countdown)
    countdown = countdown - 1

print("GO! 🏁")
```
