# ⭐ Step 2 — `else` is the "otherwise"

What if you want to do **one thing** when the rule is true, and
**another thing** when it's false?

That's what **`else`** is for.

**Delete** the `age` test lines from Step 1 and add these lines
right before the final `print` line at the bottom:

```python
difficulty = input("Easy or hard? ")

if difficulty == "hard":
    print("Good luck, brave one! 💪")
else:
    print("You got this! 🌟")
```

> 💡 Notice the **double equals** `==` — that's how Python asks
> "are these two things the same?". A single `=` means "put this
> value in this box", so they're different!
