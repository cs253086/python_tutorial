# Class 4 — Make choices! 🤔

Until now, Python did every line, no matter what. Today Python
starts **making choices**: do one thing **if** something is true,
and something **else** if it's not.

---

## 🌂 What's an `if`?

Imagine a sign outside your house:

> **IF** it's raining → take an umbrella.
> **ELSE** → wear sunglasses.

You only do **one** of these, depending on whether it's raining.
That's an `if / else`:

```
if weather == "rainy":
    print("Take an umbrella!")
else:
    print("Wear sunglasses!")
```

The **rule** (`weather == "rainy"`) is checked:
- **True** → run the first block
- **False** → run the `else` block

## 🟰 Wait — why `==` and not `=`?

- `=` means *"put this value in the box"* (like `score = 0`)
- `==` means *"are these two things the same?"*

Totally different! `=` changes things; `==` just asks a question
and gets back True or False.

## ⬅️ Indentation matters

See how the line after `if` is pushed a bit to the right? That's
how Python knows *"this line belongs to the if."* Without the
indent, Python gets confused.

In the editor, use **Tab** or **two spaces** to push a line in.
