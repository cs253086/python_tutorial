# 🏆 You did it!

You finished Class 4. Here's what you learned:

- **`if`** — only do something when a rule is true.
- **`else`** — do something else when the rule is false.
- **`==`** — asks "are these two the same?"
- **Indentation** — the push-to-the-right that shows what belongs
  to the `if`.

Your game now **changes what it says** based on the player's
choice. 🎉
